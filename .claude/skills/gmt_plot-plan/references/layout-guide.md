# GMT 图件组件排版参考指南

本文档包含组件位置分配所需的详细参考表格、计算公式和 GMT 参数模板。由 `gmt_plot:plan` 技能的第六步和第七步引用。

---

## 1. 内容密度预分析参考

### 1.1 地理区域特征分类

| 类型 | 示例区域 | 数据密集区 | 预判空白区 |
|------|---------|-----------|-----------|
| 大陆型 | 中国、美国本土、欧洲 | 陆地全域 | 周边海洋 |
| 海洋型 | 南海、太平洋某区域 | 海岸线、岛屿附近 | 深海区域 |
| 混合型 | 大陆边缘、全球图 | 陆地 + 近海 | 远洋（太平洋中部等） |
| 局部小区域 | 经纬度跨度 < 5° | 均匀分布 | 四个角落 |

### 1.2 中国及周边常用区域空白区速查

| 地理范围 | 区域类型 | 优先空白侧 | 推荐图例角 |
|---------|---------|-----------|-----------|
| 中国全图（含海域） | 大陆型 | 东南（海洋） | 右上/右下 |
| 中国全图（仅陆地） | 大陆型 | 西北/西南 | 左上/左下 |
| 华北/东北 | 大陆型 | 东南（渤海/黄海） | 右下 |
| 华南/东南沿海 | 大陆型 | 东南（南海） | 右下 |
| 西北/青藏高原 | 大陆型 | 四周均有空白 | 右上/左上 |
| 南海及周边 | 海洋型 | 远离岛屿侧 | 视岛屿位置而定 |
| 东南亚 | 混合型 | 印度洋/太平洋侧 | 左上/右上 |

### 1.3 投影对空白区判断的影响

| 投影类型 | GMT 代码 | 对空白区的影响 |
|---------|---------|--------------|
| 墨卡托 | `-JM` | 高纬度区域被拉伸放大，低纬度相对压缩 |
| 等距圆柱 | `-JQ` | 各区域均匀呈现，空白区判断最直观 |
| Lambert 等面积 | `-JN` | 适合中纬度，角落可能有投影裁剪空白 |
| Robinson | `-JR` | 全球图，边缘为曲线边界，组件应避开弯曲边缘 |
| Mollweide | `-JW` | 椭圆边界，四角有大面积空白 |
| 极射投影 | `-JS` | 圆形边界，四角有大面积空白，组件可放在角上 |
| UTM | `-JU` | 局部精准投影，角落空白区正常使用 |

## 2. 组件需求判断

| 组件 | 何时需要 | 何时不需要 |
|------|---------|-----------|
| **色标** | 有颜色映射的数据图层（地形、重力、温度等网格/颜色填充数据） | 纯矢量图（仅点线）、无颜色梯度的分类图 |
| **图例** | 多种符号/线型/颜色代表不同类别；站点分类、震级分档、断层类型等 | 单一数据类型、色标已充分说明含义 |
| **比例尺** | 大多数区域地图，尤其是展示距离信息的地图 | 全球图（纬度差异大）、纯示意图 |
| **指北针** | 投影方向非正北（斜轴/极射投影）；出版级正式图件 | 正北向上标准投影，非正式草图 |
| **插图** | 需展示区域位置关系（如中国南海诸岛插图） | 全球图、区域已足够直观 |

**判断原则：**
- 不确定是否需要时，默认添加（后续修饰可移除）
- 多个同类图例时考虑合并
- 色标是唯一固定在外侧的组件，其他组件在主图框内部竞争空间

### 组件放置优先级

| 优先级 | 组件 | 说明 |
|--------|------|------|
| 1 | **图例** | 最重要，需放在数据稀疏区且不能遮挡核心数据 |
| 2 | **插图** | 位置通常固定（如南海诸岛插图固定在右下角） |
| 3 | **比例尺** | 尺寸小，可放在图框内角落 |
| 4 | **指北针** | 尺寸最小，可放在任何角落 |
| - | **色标** | 固定在主图框外侧，不参与内部空间竞争 |

## 3. 色标（Colorbar）排版参考

### 3.1 位置选择

| 图件特征 | 推荐位置 | 理由 |
|---------|---------|------|
| 一般区域图（宽高比 < 1.5:1） | **右侧**（默认） | 符合阅读习惯，不占用上下空间 |
| 宽幅图（宽高比 ≥ 1.5:1） | **底部** | 右侧色标会过长，底部比例更协调 |
| 高幅图（高宽比 ≥ 1.5:1） | **右侧** | 充分利用纵向空间 |
| 右侧有插图或子图 | **底部**或**左侧** | 避免与插图/子图冲突 |
| 底部有子图或剖面 | **右侧** | 避免与底部元素冲突 |

### 3.2 尺寸计算

```
色标长度 = 主图框对应维度 × 0.65 ~ 0.85
  - 右侧色标：长度 = 主图框高度 × 0.70（推荐）
  - 底部色标：长度 = 主图框宽度 × 0.70（推荐）
  - 下限：不低于对应维度的 50%

色标宽度 = 0.2 ~ 0.4 cm
  - 标准：0.3 cm
  - 大图（> A3）：0.4 cm
```

### 3.3 偏移计算

```
偏移量(cm) = max(0.3, 图件短边(cm) × 0.03)
推荐范围：0.5 ~ 1.0 cm，出版级取上限
```

### 3.4 GMT 参数模板

```bash
# 右侧色标（最常用）
gmt colorbar -DjMR+o<水平偏移>c/0c+w<色标长度>c/<色标宽度>c+h

# 底部色标
gmt colorbar -DjBC+o0c/<-垂直偏移>c+w<色标长度>c/<色标宽度>c+h

# 左侧色标
gmt colorbar -DjML+o-<水平偏移>c/0c+w<色标长度>c/<色标宽度>c+h

# 典型值：
#   右侧色标水平偏移：0.5 ~ 1.0 cm
#   底部色标垂直偏移：0.5 ~ 1.0 cm
```

## 4. 图例（Legend）排版参考

### 4.1 位置优先级

| 优先级 | 位置 | 标准 GMT 参数 | 适用场景 |
|--------|------|-------------|---------|
| 1 | 右上角 | `-DjTR+o-0.3c/-0.3c` | 左下区域有密集数据（最常见） |
| 2 | 左上角 | `-DjTL+o0.3c/-0.3c` | 右下区域有密集数据 |
| 3 | 右下角 | `-DjBR+o-0.3c/0.3c` | 左上区域有密集数据 |
| 4 | 左下角 | `-DjBL+o0.3c/0.3c` | 右上区域有密集数据 |
| 5 | 中部偏右 | `-DjMR+o-0.5c/0c` | 四角都被占用（罕见） |

### 4.2 区域特定建议

| 地理区域 | 推荐位置 | 原因 |
|---------|---------|------|
| 中国（含海域） | 右上角或右下角 | 东南侧海洋空旷，不遮挡陆地数据 |
| 中国（仅陆地） | 左上角或右上角 | 西部边界不规则、数据稀疏 |
| 东南亚（含南海） | 左上角或右上角 | 海洋侧空旷 |
| 欧洲 | 左上角 | 大西洋侧空旷 |
| 北美 | 右下角或左上角 | 视具体范围而定 |
| 南美 | 右下角或左下角 | 大西洋侧空旷 |
| 非洲 | 左下角或右下角 | 两侧海洋均可 |
| 全球图 | 左下角或右下角 | 太平洋是最大空白区 |
| 海洋区域 | 最远离陆地的角落 | 不遮挡海岸线和岛屿标注 |
| 极地区域 | 最远离研究站的角落 | 避免遮挡科考站标注 |

### 4.3 偏移计算

```
偏移量(cm) = max(0.2, 图框短边(cm) × 0.02)
推荐范围：0.3 ~ 0.5 cm
大图（> A4）：0.5 ~ 0.8 cm
```

### 4.4 GMT 参数模板

```bash
# 推荐方式：-Dj 参考位置 + 偏移
gmt legend -DjTR+o-0.3c/-0.3c+w<图例宽度>c -l1p

# 备选方式：图框坐标（-Dx，值域 0-1，左下角原点）
gmt legend -Dx0.92c/0.92c+w<图例宽度>c -l1p

# 图例宽度建议：3.0 ~ 5.0 cm（视标注文字长度而定）
```

## 5. 比例尺（Scale Bar）排版参考

### 5.1 位置与偏移

- 默认位置：**左下角**（符合地图阅读习惯）
- 备选位置：右下角
- 偏移范围：0.5 ~ 1.5 cm（约占图框对应边长的 5-10%）
- 不与图例或指北针同角

### 5.2 GMT 参数模板

```bash
# 方式一：地图坐标定位（推荐，自动适配投影）
gmt basemap -Lg<经度>/<纬度>+w<距离>k+c<经度>/<纬度>+f

# 方式二：相对位置定位
gmt basemap -LjBL+o<X偏移>c/<Y偏移>c+w<距离>k+f

# 参数说明：
#   -Lg: 地图坐标位置绘制
#   -Lj: 参考位置（BL=左下角, BR=右下角）
#   +w:  实际距离（k=km）
#   +c:  标注文字位置
#   +f:  花哨样式（交替黑白方块）

# 示例：左下角偏移 0.6cm，200 km 比例尺
gmt basemap -LjBL+o0.6c/0.6c+w200k+f
```

### 5.3 比例尺距离选择

选取图幅宽度的 1/4 ~ 1/3 对应的实际距离，取整到合适数量级：

| 图幅实际跨度 | 推荐比例尺距离 |
|------------|-------------|
| ~3000 km | 500 或 1000 km |
| ~1000 km | 200 或 500 km |
| ~500 km | 100 或 200 km |
| ~100 km | 20 或 50 km |
| ~50 km | 10 或 20 km |

常用整数值：1, 2, 5, 10, 20, 50, 100, 200, 500, 1000 km

## 6. 指北针（Compass）排版参考

### 6.1 必要性判断

| 投影类型 | GMT 代码 | 是否需要 | 原因 |
|---------|---------|---------|------|
| 墨卡托 | `-JM` | **可选** | 经线垂直，上方即正北 |
| 等距圆柱 | `-JQ` | **可选** | 同上 |
| Lambert 等面积 | `-JN` | **可选** | 正轴投影，上方即正北 |
| Robinson | `-JR` | **可选** | 伪圆柱投影，整体北在上 |
| Mollweide | `-JW` | **可选** | 同 Robinson |
| UTM | `-JU` | **可选** | 正北向上 |
| 斜轴投影 | `-JO` | **必须** | 图幅上方不是北方向 |
| 极射投影 | `-JS` | **必须** | 极点投影，方向关系复杂 |
| 横轴投影 | `-JT` | **必须** | 图幅上方不是北方向 |
| 出版级正式图件 | 任意 | **推荐添加** | 提升专业性和完整性 |

### 6.2 位置与偏移

- 默认：**右上角**（地图学惯例），备选：左上角
- 不与图例同角，不与比例尺同角
- 偏移：`max(0.4, 图框短边(cm) × 0.03)`，推荐 0.4 ~ 1.0 cm
- 尺寸：0.8 ~ 2.0 cm

### 6.3 GMT 参数模板

```bash
# 右上角指北针
gmt basemap -TdjTR+o-<X偏移>c/-<Y偏移>c+w<尺寸>c+f<字体>

# 左上角指北针
gmt basemap -TdjTL+o<X偏移>c/-<Y偏移>c+w<尺寸>c+f<字体>

# 参数说明：
#   -Td: 指北针（d = directional / compass rose）
#   jTR/jTL: 参考位置（TR=右上角, TL=左上角）
#   +o: 偏移（负值向内侧）
#   +w: 尺寸（cm）
#   +f: "N"标注字体规格

# 示例：右上角偏移 0.5cm，1.0cm 指北针
gmt basemap -TdjTR+o-0.5c/-0.5c+w1.0c+f8p,Helvetica,black
```

## 7. 插图（Inset）排版参考

| 场景 | 是否需要 | 说明 |
|------|---------|------|
| 中国区域地图 | **推荐** | 右下角添加南海诸岛插图 |
| 包含争议区域的地图 | **推荐** | 插图展示完整疆域 |
| 大区域中包含小区域焦点 | **可选** | 缩略图展示焦点位置 |
| 全球图 | 不需要 | — |

**中国地图南海诸岛插图标准：**
- 位置：主图框右下角
- 大小：主图框面积的 8-15%
- 与主图框间距：0.3 ~ 0.5 cm

```bash
# GMT inset 方式
gmt inset begin -DjBR+o-0.3c/0.3c+w3.5c/3c
  # ... 南海诸岛绘制命令 ...
gmt inset end
```

## 8. 组件冲突检查

### 8.1 冲突检查清单

1. **图例 vs 指北针**：不能同角 → 指北针让步，移至对角
2. **图例 vs 比例尺**：不能同角 → 比例尺让步，移至对角
3. **图例 vs 插图**：图例不能叠在插图上 → 图例移至其他空白角
4. **色标 vs 插图/子图**：不能同侧 → 色标换边
5. **图例 vs 数据密集区**：图例必须在预判空白区 → 换至最空白角
6. **比例尺 vs 指北针**：避免同角，两者尺寸都小，错开放置

### 8.2 冲突解决优先级

| 优先级 | 组件 | 让步策略 |
|--------|------|---------|
| 1 | 插图 | 位置固定，不让步 |
| 2 | 图例 | 优先占据最佳空白角，其他组件避让 |
| 3 | 比例尺 | 可在左下/右下角之间切换 |
| 4 | 指北针 | 可在右上/左上角之间切换，尺寸最小最灵活 |
| 5 | 色标 | 位置相对固定（外侧），但可在右/底/左侧切换 |

### 8.3 经典无冲突布局

| 图例 | 比例尺 | 指北针 | 插图 | 适用场景 |
|------|--------|--------|------|---------|
| 右上角 | 左下角 | 左上角 | 右下角 | 经典四角布局（中国地图） |
| 右上角 | 左下角 | 左上角 | — | 无插图标准布局 |
| 左上角 | 右下角 | 右上角 | — | 右下数据密集 |
| 右下角 | 左下角 | 左上角 | — | 右上数据密集 |
